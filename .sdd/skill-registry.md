## Project Context

- Primary runtime: Go module `github.com/lleontor705/cortex-ia`; manifest language version Go 1.26.1; detected toolchain Go 1.26.4.
- Product: cross-platform CLI/TUI ecosystem configurator using Bubble Tea, Bubbles, Lip Gloss, and YAML v3.
- Architecture: `cmd/cortex-ia` entry point with package-oriented `internal/` modules; adapter strategy under `internal/agents`; component injectors under `internal/components`; Prepare → Apply pipeline with rollback support.
- Agent architecture: 4 supported adapters — Claude Code, OpenCode, VS Code Copilot, and Codex; delegation capabilities vary by adapter.
- SDD architecture: nine phases including init; the orchestrator dispatches ForgeSpec-ready work directly to implement; phase artifacts use ForgeSpec contracts and Cortex/OpenSpec persistence.
- Quality: `gofmt -s`, `go vet`, golangci-lint v2 (`errcheck`, `govet`, `staticcheck`, `unused`, `ineffassign`).
- CI/CD: GitHub Actions reusable Go quality/security workflows, issue-first PR validation, and GoReleaser.
- Workflow: Conventional Commits; typed branch names; PRs must link an approved issue and carry exactly one `type:*` label.
