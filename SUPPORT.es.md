# Soporte

Cortex-IA es un proyecto de código abierto y de código disponible mantenido en abierto.
El soporte se realiza a través de canales públicos para que cada respuesta siga siendo
descubrible para el resto de la comunidad.

## Dónde obtener ayuda

| Quiero...                   | Usa                                                                                            |
| --------------------------- | ---------------------------------------------------------------------------------------------- |
| Reportar un error           | [Informe de error](https://github.com/lleontor705/cortex-ia/issues/new?template=bug_report.yml)       |
| Solicitar una función       | [Solicitud de función](https://github.com/lleontor705/cortex-ia/issues/new?template=feature_request.yml) |
| Hacer una pregunta          | [GitHub Discussions](https://github.com/lleontor705/cortex-ia/discussions)                      |
| Reportar una vulnerabilidad | [SECURITY.md](SECURITY.md) y GitHub Security Advisories                                         |

Los issues en blanco están deshabilitados a propósito. Usa los formularios anteriores para que
recibamos los detalles necesarios para reproducir y clasificar tu informe.

## Documentación

Antes de abrir una solicitud, los siguientes recursos pueden responder tu pregunta:

- **[README.md](README.md)** — descripción general del proyecto e inicio rápido.
- **[docs/](docs/)** — índice de documentación, que incluye
  [installation.md](docs/installation.md), [quickstart.md](docs/quickstart.md),
  [configuration.md](docs/configuration.md) y [mcp.md](docs/mcp.md).
- **[CHANGELOG.md](CHANGELOG.md)** — historial de versiones y cambios recientes.
- **[CONTRIBUTING.md](CONTRIBUTING.md)** — reglas de flujo de trabajo, ramas y commits.

## Expectativas de respuesta

Este proyecto lo mantienen voluntarios según su mejor esfuerzo. No podemos
prometer tiempos de respuesta fijos, pero los informes bien acotados con pasos de
reproducción claros se clasifican primero. Los informes de seguridad siguen los plazos indicados en
[SECURITY.md](SECURITY.md).
