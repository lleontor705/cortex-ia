# Support

**English** | [Español](SUPPORT.es.md)

Cortex-IA is a source-available, open-source project maintained in the open.
Support happens through public channels so that every answer stays discoverable
for the rest of the community.

## Where to Get Help

| I want to...            | Use                                                                                            |
| ----------------------- | ---------------------------------------------------------------------------------------------- |
| Report a bug            | [Bug report](https://github.com/lleontor705/cortex-ia/issues/new?template=bug_report.yml)       |
| Request a feature       | [Feature request](https://github.com/lleontor705/cortex-ia/issues/new?template=feature_request.yml) |
| Ask a question          | [GitHub Discussions](https://github.com/lleontor705/cortex-ia/discussions)                      |
| Report a vulnerability  | [SECURITY.md](SECURITY.md) and GitHub Security Advisories                                       |

Blank issues are disabled on purpose. Please use the forms above so we receive
the details needed to reproduce and triage your report.

## Response Expectations

This project is maintained by volunteers on a best-effort basis. We cannot
promise fixed response times, but well-scoped reports with clear reproduction
steps are triaged first. Security reports follow the timelines in
[SECURITY.md](SECURITY.md).
