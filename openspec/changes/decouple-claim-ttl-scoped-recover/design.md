# Design — Decouple Claim TTL & Scoped Self-Recovery (summary)

> Canonical integrated contract: [plan.md](plan.md). This file summarizes the design sections; plan.md is authoritative.

- **Policy model**: `maintenancePolicy = { interval_ms: 30000, status_timeout_ms: 5000, stale_progress_ms: 900000, ttl: "30m" }`. `ttl` is independent claim validity per heartbeat renewal; `stale_progress_ms` remains the no-host-activity orphan window (stop call sites ~653/679/751), keeping stale claims detectable. Progress-based dynamic TTL rejected (couples orthogonal concerns; breaks harness determinism).
- **Plugin tool**: `cortex_ia_work_recover_own(task_id)` — in-memory ownership check (`workAuthority.get(task_id)?.sessionID === context.sessionID`, fail closed with zero CLI calls), then `cortex(["work","recover","--task",task_id,"--owner",controllerIdentity(sessionID)])`, then stop maintenance, drop the stale handle, save state (mirrors the `work_approve` cleanup pattern). Mutation map: `work_recover_own: ["implement"]`; `work_recover` stays `["orchestrator"]`; unclassified capabilities keep failing closed (`BRIDGE_POLICY_UNCLASSIFIED`).
- **Go surface**: `work recover [--task <id> --owner <identity>]` — flags mandatory together; unscoped form unchanged; scoped form calls `Store.RecoverWorkScoped(ctx, taskID, owner)` under BEGIN IMMEDIATE reusing a refactored shared per-task helper from `RecoverWork`; typed sentinel `ErrScopedRecoverDenied` (owner_mismatch | claim_not_expired | task_not_found), zero writes on denial.
- **Sequence**: expiry → same-session `cortex_ia_work_recover_own` → two-layer ownership check (in-memory + durable) → claim/lease release → handle dropped → fresh re-claim with new attempt counter; tokens never resurrect.
- **Trade-offs**: pure plugin-side gating rejected (durable state must be enforced in SQLite); extending `work_reconcile` rejected (different fail-closed semantics); ttl=30m bounds worst-case orphan visibility at ~45 minutes.
